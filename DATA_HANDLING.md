# Data handling

This repository is a static, public toy project. Its pricing code and test
scripts make no network requests, collect no telemetry, and do not send source
code to Veripsa. Cloning and dependency installation contact GitHub and your
configured Python package index in the normal way.

The project-hosted Veripsa GitHub App has been suspended since **2026-08-18**.
The bundled recording is historical; the quickstart does not require or install
the App. Running the local tests does not produce a Veripsa GitHub check.

## Public repository content

Files, commit history, and any GitHub issue or pull-request content you publish
may be visible to others. Use synthetic fixtures and remove credentials,
personal information, customer identifiers, and private repository names before
publishing changes. Do not include secrets in bug reports.

## Historical hosted service

This fixture does not define a current hosted-service data contract. The old
upstream contract and demo repositories are now private, so their past retention
and deletion claims should not be treated as current availability or policy.
The historical manifest and recording remain here to explain the toy scenario.

For the standalone local analyzer, follow
[Veripsa Core’s current documentation](https://github.com/RollNuts/veripsa).
